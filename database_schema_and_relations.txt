========================================================================
WorkHub: Complete Database Schema & Relations Guide
========================================================================

This document outlines the entire database architecture of the WorkHub application, listing every table, column details, indices, foreign keys, and their entity-relationship (ER) connections.

========================================================================
1. Entity-Relationship Overview (Text-based ERD)
========================================================================

    [users]
       |
       |-- (1:N) --> [company_users] <-- (N:1) -- [companies]
       |                                             |
       |-- (1:N) --> [projects] <-------- (N:1) ------|
       |                |
       |                |-- (1:N)
       |                            |
       |-- (1:N) --> [tasks] <------|
       |                |
       |                |-- (1:N) --> [task_images]
       |                |
       |                |-- (1:N) --> [task_histories]
       |
       |-- (1:N) --> [comments] (Polymorphic: attaches to Tasks / Notes)
       |
       |-- (1:N) --> [notes] (Polymorphic-like: attaches to Projects / Tasks / Companies / Users)
       |
       |-- (1:N) --> [notifications] (Polymorphic: standard Laravel notifications table)
       |
       |-- (1:N) --> [company_invitations] <-- (N:1) -- [companies]

========================================================================
2. Table Schemas & Columns
========================================================================

------------------------------------------------------------------------
A. users
------------------------------------------------------------------------
Represents accounts of all administrators, managers, and team members.
- id (BigInt, PK, Auto Increment)
- name (String/VarChar, 255)
- email (String/VarChar, 255, Unique)
- email_verified_at (Timestamp, Nullable)
- password (String/VarChar, 255)
- profile_image (String/VarChar, 255, Nullable)
- remember_token (String/VarChar, 100, Nullable)
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
B. companies
------------------------------------------------------------------------
Represents workspace organizations.
- id (BigInt, PK, Auto Increment)
- name (String/VarChar, 255)
- code (String/VarChar, 255, Unique) - Join code for organization
- deleted_at (Timestamp, Nullable) - Soft deletes
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
C. company_users
------------------------------------------------------------------------
Pivot table defining user membership and roles in companies.
- id (BigInt, PK, Auto Increment)
- company_id (BigInt, FK references companies.id, Cascade Delete)
- user_id (BigInt, FK references users.id, Cascade Delete)
- role (Integer/TinyInt) - 0 = Member, 1 = Admin
- is_approved (Boolean, Default: false) - Join request approval
- deleted_at (Timestamp, Nullable) - Soft deletes
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
D. projects
------------------------------------------------------------------------
Represents project workspaces within organizations or personal spaces.
- id (BigInt, PK, Auto Increment)
- name (String/VarChar, 255)
- slug (String/VarChar, 255)
- theme (String/VarChar, 7, Nullable) - HEX color theme
- company_id (BigInt, FK references companies.id, Nullable, Cascade Delete)
- user_id (BigInt, FK references users.id, Cascade Delete)
- status (Integer/TinyInt, Default: 1)
- priority (Integer/TinyInt, Default: 2)
- deleted_at (Timestamp, Nullable) - Soft deletes
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
E. tasks
------------------------------------------------------------------------
Represents tasks assigned to users inside or outside projects.
- id (BigInt, PK, Auto Increment)
- title (String/VarChar, 255)
- description (Text, Nullable)
- due_date (Date, Nullable)
- project_id (BigInt, FK references projects.id, Nullable, Cascade Delete)
- user_id (BigInt, FK references users.id, Cascade Delete)
- assigned_to (BigInt, FK references users.id, Nullable, Set Null)
- status (Integer/TinyInt, Default: 1) - 1=To Do, 2=In Progress, 3=Completed, 4=On Hold
- priority (Integer/TinyInt, Default: 2) - 1=Low, 2=Medium, 3=High, 4=Urgent
- type (Integer/TinyInt, Default: 1) - 1=Feature, 2=Bug, 3=Improvement, 4=Task
- deleted_at (Timestamp, Nullable) - Soft deletes
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
F. task_images
------------------------------------------------------------------------
Represents file uploads and images attached to tasks.
- id (BigInt, PK, Auto Increment)
- task_id (BigInt, FK references tasks.id, Cascade Delete)
- path (String/VarChar, 255)
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
G. task_histories
------------------------------------------------------------------------
Audit trail logging state and status changes for tasks.
- id (BigInt, PK, Auto Increment)
- task_id (BigInt, FK references tasks.id, Cascade Delete)
- user_id (BigInt, FK references users.id, Cascade Delete)
- field (String/VarChar, 255)
- old_value (Text, Nullable)
- new_value (Text, Nullable)
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
H. notes
------------------------------------------------------------------------
Custom polymorphic-like notes attached to tasks, projects, organizations, or personal space.
- id (BigInt, PK, Auto Increment)
- title (String/VarChar, 255)
- description (Text, Nullable)
- note_type (Integer/TinyInt) - 1=Project, 2=Task, 3=Organization, 4=Personal
- note_type_id (BigInt) - Target model's primary key
- user_id (BigInt, FK references users.id, Cascade Delete)
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
I. comments
------------------------------------------------------------------------
Generic polymorphic comments attached to tasks or notes.
- id (BigInt, PK, Auto Increment)
- user_id (BigInt, FK references users.id, Cascade Delete)
- content (Text)
- commentable_type (String/VarChar, 255)
- commentable_id (BigInt)
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
J. notifications
------------------------------------------------------------------------
Standard Laravel database notification store.
- id (UUID, PK)
- type (String/VarChar, 255)
- notifiable_type (String/VarChar, 255)
- notifiable_id (BigInt)
- data (Text)
- read_at (Timestamp, Nullable)
- created_at / updated_at (Timestamps)

------------------------------------------------------------------------
K. company_invitations
------------------------------------------------------------------------
Stores pending invites sent to prospective members.
- id (BigInt, PK, Auto Increment)
- company_id (BigInt, FK references companies.id, Cascade Delete)
- email (String/VarChar, 255)
- token (String/VarChar, 255, Unique)
- role (Integer/TinyInt, Default: 0) - 0=Member, 1=Admin
- expires_at (Timestamp)
- created_at / updated_at (Timestamps)

========================================================================
3. Eloquent Connections & Relationships Map
========================================================================

- User
    - hasMany(CompanyUsers::class, 'user_id')
    - belongsToMany(Company::class, 'company_users')
    - hasMany(Project::class, 'user_id')
    - hasMany(Task::class, 'user_id') (Tasks created by user)
    - hasMany(Task::class, 'assigned_to') (Tasks assigned to user)
    - hasMany(Comment::class)
    - hasMany(Note::class)

- Company
    - hasMany(CompanyUsers::class, 'company_id')
    - belongsToMany(User::class, 'company_users')
    - hasMany(Project::class, 'company_id')
    - hasMany(CompanyInvitation::class)

- CompanyUsers
    - belongsTo(Company::class)
    - belongsTo(User::class)
    - hasMany(Task::class, 'assigned_to', 'user_id')

- Project
    - belongsTo(Company::class)
    - belongsTo(User::class)
    - hasMany(Task::class)

- Task
    - belongsTo(Project::class)
    - belongsTo(User::class)
    - belongsTo(User::class, 'assigned_to')
    - hasMany(TaskImage::class)
    - hasMany(TaskHistory::class)
    - morphMany(Comment::class)

- Note
    - belongsTo(User::class)
    - morphMany(Comment::class)
    - noteable (Custom attribute returning dynamic Model based on note_type and note_type_id)

- Comment
    - belongsTo(User::class)
    - morphTo(commentable)

- CompanyInvitation
    - belongsTo(Company::class)
